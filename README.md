# Gestion des tâches

Application Python simple de gestion de tâches en mode console.

## Fonctionnalités
- Ajouter une tâche (titre non vide)
- Afficher les tâches avec leur numéro
- Rechercher une tâche par mot-clé
- Quitter le programme

## Étapes réalisées
- Création du menu avec une boucle while
- Ajout des fonctions ajouter, afficher et rechercher
- Test du programme et publication sur GitHub
